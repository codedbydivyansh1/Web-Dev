Absolute Path

In coding, an absolute path is the complete address of a file or folder, starting from the root directory. It shows the exact location of a file on the system, no matter where you currently are in the folder structure. This path is fixed and doesn't change based on your position in the system. For example, on Windows it might look like C:\Users\John\Documents\file.txt, and on Linux or macOS it could be /home/user/file.txt. Absolute paths are useful when you need to access a specific file from anywhere in the system.

Relative Path

A relative path, on the other hand, is a way to describe the location of a file or folder based on your current position in the folder structure (called the working directory). It doesn’t start from the root, but instead gives directions relative to where you currently are. For example, if you’re inside the folder /home/user/ and your file is in a subfolder called docs, the relative path would be docs/file.txt. Relative paths are shorter and more flexible, and they are commonly used in projects so the code works correctly on different computers or environments.
