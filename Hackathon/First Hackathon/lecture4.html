Lecture 4 HTML forms

What is HTML Forms?

An HTML form is used to collect user input. It sends data to a server for processing (e.g., login forms, search bars, etc.).

Tags used in html forms

Input--> Used for text fields, checkboxes, etc.
label--> Defines labels for inputs
textarea--> Multi-line text input
Select--> Dropdown list
Option--> Options in Dropdown
Button--> Clickable button

Attribute and its use

Attribute Use
name Key name for submitted data
value Default input value
placeholder Hint inside the input
required Makes field mandatory
readonly Cannot be modified
